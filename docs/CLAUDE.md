| `adr/0050-sdk-lifecycle-domain.md` | Ordered start/stop domain (`lifecycle`): the SDK had every piece of a service's startup and no assembly of them, and **two lifecycle defects found in this repository are the argument** — ADR 0043 (one endless stream spent the entire drain budget, making `DRAIN_TIMEOUT` the normal outcome of every deployment) and ADR 0047 §D9 (the engine closed the socket it had just handed to the handler, so no hijack worked at all). | `adr/0052-sdk-lock-domain.md` | Mutual-exclusion domain (`lock`): 19th core sibling, **no registry**; `Locker` frozen at two methods and `Lease` at three, neither taking a TTL — a lease lifetime is configured where the locker is wired, so the zero that would be read as "already expired" cannot be typed in a hot path. | `adr/0053-sdk-events-domain.md` | In-process event bus domain (`events`), and **the line between it and the `queue` domain that comes next** — drawn before either could drift, because a library that "supports both" reliably guarantees neither. `events` is in-process, synchronous, same-goroutine, same transaction: no durability, no retry, no dead-letter path, and if the process dies mid-dispatch the event never happened. A caller who wants "asynchronous but reliable" is sent to `queue`, not served the asynchrony without the reliability — so there is deliberately no async mode, not even as an option (§Why not). The routing key is the event's concrete Go TYPE, never a name: the compiler mints it, two packages cannot both spell `"user.created"`, and an interface type is REFUSED at registration because `reflect.TypeOf` never yields one and such a listener would be listed and never called (ADR 0031). Typing is erased-plus-generic because Go methods take no type parameters: `Listener func(ctx, any) error` with a package-level `On[E]` that derives the key and asserts — a `Bus[E]` would carry exactly one event type, which is a channel. **The assertion is measured, not asserted: 2.4 ns per listener call against an identical erased control, 3.5 % of a dispatch**, and the 16 B the caller pays to box the event is published beside it rather than hidden behind the other rows' `0 allocs/op`. Listeners run in ascending priority with ties in registration order, sorted at registration so the read path never allocates. Stopping propagation is an AUTHORITY declared at the wiring site (`MayHalt`) and exercised by returning the `Halt` sentinel — an unauthorised halt does NOT stop the dispatch and is reported, because honouring it makes the permission decorative and swallowing it leaves a listener convinced it vetoed an event every sibling then saw. A listener PANIC is recovered on the publisher's goroutine, carries the originating stack in a field, never hijacks the code, is never read as a halt, and does not stop the siblings. **`kernel/topic` was read and deliberately NOT used** — its per-subscriber buffer makes `Publish` return before the listeners have run and puts `Halt` on the wrong side of a channel; the domain takes `kernel/snapshot`, the primitive `topic` itself is built on. ## ADR conventions

- Sequential numbering (`0001`, `0002`, …). Never reuse a number.
- Filename slug = short kebab-case summary of the decision.
- Header fields: `Status`, `Date`, `Deciders`, optional `Supersedes`, `Superseded by`, `Amends`, `Related`.
- Standard sections: Context, Decision, Consequences / Semantics, Breaking changes, Why not …, Deferred, References.
- Immutable after merge. Supersede via a new ADR that references the old one (e.g. ADR 0005 supersedes ADR 0002 §Registry; ADR 0006 amends ADR 0005 §Registry).

## Registry coupling

The dotted-quad allocation table in `adr/0005-…` + the extension in `adr/0006-…` is the **documentary source of truth**; the AST audit test in `internal/kernel/errs/registry_external_test.go` embeds the same table as the **executable source of truth**. Keep the two in sync manually on every change — the audit catches drift on uniqueness and `reason = screamingSnake(varName)` OR `screamingSnake(CodeConst − "Code")` (ADR 0006/0020) over every package in `//:audit_sources`.

`docs/error-codes.yaml` is the **generated human-readable mirror** of every `errs.Code` constant in the tree (one entry per code: dotted-quad, const name, hex, package). Regenerate with `make error-codes` (`scripts/gen-error-codes.sh`); the `scripts/pre-commit/check-error-codes-drift.sh` guard fails the commit when it is stale. It is a convenience index, not authoritative — the AST audit remains the executable gate.

## Do NOT

- Put feature documentation here. Packages document themselves via `README.md` next to their code.
- Delete an accepted ADR. Mark it superseded by adding a new ADR and updating both `Status` lines.
- Re-number existing ADRs, even after a supersede chain.
- Edit an ADR's Decision section after merge — write a new ADR.
