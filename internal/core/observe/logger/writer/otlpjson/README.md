# otlpjson

The codes and sentinels of the OTLP/JSON log writer
(`internal/service/observe/logger/writer/otlpjson`): range `0.3.104.*` —
`OTLP_LOGS_ENDPOINT_INVALID`, `OTLP_LOGS_EXPORT_REJECTED`,
`OTLP_LOGS_EXPORT_UNAVAILABLE`, `OTLP_LOGS_PARTIAL_SUCCESS`. Declared here as
ADR 0160 asks; the engine declares none. See `CLAUDE.md`.
