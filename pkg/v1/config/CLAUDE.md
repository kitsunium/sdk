# pkg/v1/config/

## Purpose

Public facade for the SDK configuration domain (ADR 0028). Aliases the
`Source`/`Validator`/`Watcher` port, exposes the generic `Load[T]`, the
`EnvSource`/`FileSource`/`PollWatcher` constructors, and the sentinels.
Stdlib-only → dep-light; cross-OS (poll watcher).

## Surface

| Symbol | Notes |
|---|---|
| `Source` / `Validator` / `Watcher` | aliases onto `core/config` |
| `Load[T](target, sources...)` | merge (later wins) + decode + Validate |
| `EnvSource(prefix)` / `FileSource(format, path)` / `PollWatcher(path, interval)` | constructors |
| `SourceFailed` / `DecodeFailed` / `ValidationFailed` / `WatchFailed` | sentinels |

## Conventions

- **Type aliases, not new types**; `Load` is generic + delegates.
- **`FileSource` needs the codec registered** — blank-import `pkg/v1/codec` (or the format's package).
- Env values are JSON-coerced **only when the whole value is one complete JSON
  document** (numbers/bools typed); anything else keeps its exact string, so
  `0A0A01`, `1500ms`, `10.45.0.0/16` and `2026-09-03` survive intact. Cross-OS
  poll watch.
- README generated by gomarkdoc; edit the `config.go` doc comment + `make docs-readme`.

## Do NOT

- Reimplement merge/decode here — the facade is aliases + the `Load` wrapper.
