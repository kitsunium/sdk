# pkg/v1/resilience/

## Purpose

Public facade for the SDK reliability policies (ADR 0026). Aliases the
`Operation`/`Runner` port + `*Config` types, re-exports the five constructors
(`NewRetry`/`NewCircuitBreaker`/`NewRateLimiter`/`NewBulkhead`/`NewTimeout`) and
the outcome sentinels. Stdlib-only → dep-light; cross-OS portable.

## Surface

| Symbol | Notes |
|---|---|
| `Operation` / `Runner` | aliases onto `core/resilience` |
| `RetryConfig` / `BreakerConfig` / `RateLimiterConfig` | aliases onto `service/resilience` |
| `NewRetry` / `NewCircuitBreaker` / `NewRateLimiter` / `NewBulkhead` / `NewTimeout` | constructors |
| `RetryExhausted` / `CircuitOpen` / `RateLimited` / `BulkheadFull` / `TimeoutExceeded` | sentinels (`errs.HasReason`/`HasCode`) |

## Conventions

- **Type aliases, not new types**; constructors are thin delegations.
- **Compose by nesting**: `Retry(Breaker(Timeout(op)))` via Runner-in-Operation.
- README generated by gomarkdoc; edit the `resilience.go` doc comment + `make docs-readme`.

## Do NOT

- Reimplement policy logic here — the facade is aliases + constructor wrappers.
