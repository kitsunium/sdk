# pkg/v1/resilience/

## Purpose

Public facade for the SDK reliability policies (ADR 0026). Aliases the
`Operation`/`Runner` port + `*Config` types, re-exports the five constructors
(`NewRetry`/`NewCircuitBreaker`/`NewRateLimiter`/`NewBulkhead`/`NewTimeout`) and
the outcome sentinels. Stdlib-only → dep-light; cross-OS portable.

## Surface

| Symbol | Notes |
|---|---|
| `Operation` / `Runner` | aliases onto `core/resilience` |
| `RetryConfig` / `BreakerConfig` / `RateLimiterConfig` | aliases onto `service/resilience` |
| `RetryConfig.Retryable` / `BreakerConfig.Retryable` | `func(error) bool` — deterministic errors return verbatim (nil = replay/count everything) |
| `NewRetry` / `NewCircuitBreaker` / `NewRateLimiter` / `NewBulkhead` / `NewTimeout` | constructors |
| `RetryExhausted` / `CircuitOpen` / `RateLimited` / `BulkheadFull` / `TimeoutExceeded` | sentinels (`errs.HasReason`/`HasCode`), all `EX_TEMPFAIL` |
| `PolicyMisconfigured` | sentinel for a policy that cannot honour its config — **permanent**, `EX_CONFIG`, never retry (ADR 0031) |

## Conventions

- **Type aliases, not new types**; constructors are thin delegations.
- **Compose by nesting**: `Retry(Breaker(Timeout(op)))` via Runner-in-Operation.
- **No inert policies** (ADR 0031): a non-positive knob is clamped to a working
  floor where one is obvious (`BreakerConfig.OpenDuration`→30s) and refused
  where it is not. A policy never silently declines to do its job.
- **One classifier for both policies**: `Retryable` has the same shape in
  `RetryConfig` and `BreakerConfig`, so a nested stack shares a single predicate.
- README generated by gomarkdoc; edit the `resilience.go` doc comment + `make docs-readme`.

## Do NOT

- Reimplement policy logic here — the facade is aliases + constructor wrappers.
