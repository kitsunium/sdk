# pkg/v1/net/

## Purpose

The net family's public facades (ADR 0155). This directory holds no Go code: it
is a prefix, not a package, and there is no `github.com/kitsunium/sdk/pkg/v1/net`
to import. Each member is a package of the `pkg` module with its own
`CLAUDE.md`, `README.md` (generated by gomarkdoc from its doc comment, ADR 0008)
and, where it measures something, `BENCH.md`. A member is imported by its full
path — `github.com/kitsunium/sdk/pkg/v1/net/server` — and links what it imports
and never this directory, because Go links a package's imports and not its
parent (the measurement ADR 0155 records). Two members import a sibling, and
say so: `server` and `client` both take a `tlsid.Identity`.

## The rule that put them together

A domain belongs here when it moves bytes between processes over a socket
(ADR 0029): the inbound engine (`server`) and the outbound guarded client
(`client`), the TLS and mutual-TLS identity both ends present (`tlsid`), and the
three things served over the inbound engine's HTTP — a Server-Sent Events
stream (`sse`), a WebSocket connection (`websocket`, ADR 0047) and a file tree
(`static`, ADR 0130). They share one contract, `internal/core/net`, which owns
every `0.2.11.*` sentinel, and the engines at the same paths under
`internal/service/net`. A private socket between processes of ONE machine is the
proc family's (`ipc`, ADR 0148), and what a caller may do once a request has
arrived is the security family's (`pkg/v1/security`).

## Members

| Package | What it publishes | Aliases onto | README |
|---|---|---|---|
| `server/` | `New` → a `Server` of stream `Group`s and `PacketGroup`s, `Chain` / `ChainPacket`, the drain announced through `DrainSignal` rather than imposed (ADR 0029, ADR 0043) | `internal/core/net`, `internal/service/net/server` | `server/README.md` |
| `client/` | `New(cfg, tlsid.Identity, Policy, CallHook)` → a `Client` whose `Policy` is enforced in the transport; a refusal is `RequestDenied` (ADR 0029) | `internal/core/net`, `internal/service/net/client` | `client/README.md` |
| `tlsid/` | `New` for material in memory, `Load` for material on disk → an `Identity` shared by `server` and `client`; `MaterialInvalid`, `HandshakeFailed` (ADR 0029) | `internal/core/net`, `internal/service/net/tlsid` | `tlsid/README.md` |
| `sse/` | `New(w, r, opts…)` → a `Stream` with keep-alive, `Retry` and a write timeout; `DrainSignal` (ADR 0029, ADR 0043) | `internal/core/net`, `internal/service/net/sse` | `sse/README.md` |
| `websocket/` | `Upgrade` → a `Conn`, RFC 6455 in the stdlib, the origin checked by default; `DrainSignal` (ADR 0047, ADR 0069) | `internal/core/net`, `internal/service/net/websocket` | `websocket/README.md` |
| `static/` | `New(fsys, Config)` → an `http.Handler` that never lists a directory and sends the security headers on every answer; `Misconfigured` (ADR 0130) | `internal/core/net`, `internal/service/net/static` | `static/README.md` |

`server`, `client` and `tlsid` moved here from the root of `pkg/v1`, and `sse`,
`websocket` and `static` from under the `server` facade, in one minor release,
with no alias left at the old paths — a clean break, permitted only while the
module is v0 (ADR 0155 §4, extending ADR 0040). `sse`, `websocket` and `static`
were never `server`'s children in the link graph — none of them imports it — so
they are its siblings here, as they already were under `internal/service/net`.

## Do NOT

- Put Go code in this directory. A file here would publish a package nobody
  designed, at a path every member would then appear to belong to.
- Declare an error code in a member: every net sentinel is declared in
  `internal/core/net` and re-exported (`internal/core/net/CLAUDE.md`).
- Hand-edit a member's `README.md`: edit its doc comment and run
  `make docs-readme`, whose `--repository.path` names the member's full path.
- Leave an alias package at a member's old path, at the root of `pkg/v1` or
  under `server`. ADR 0155 §4 refuses it: it would double the surface for
  consumers nobody can name.
