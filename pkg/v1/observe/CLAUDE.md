# pkg/v1/observe/

## Purpose

The observe family's public facades (ADR 0155). This directory holds no Go
code: it is a prefix, not a package, and there is no
`github.com/kitsunium/sdk/pkg/v1/observe` to import. Each member is a package
of the `pkg` module with its own `CLAUDE.md`, `README.md` (generated by
gomarkdoc from its doc comment, ADR 0008) and, where it measures something,
`BENCH.md`. A member is imported by its full path —
`github.com/kitsunium/sdk/pkg/v1/observe/metrics` — and links what it imports
and never this directory or its siblings, because Go links a package's imports
and not its parent (the measurement ADR 0155 records). One member imports
another on purpose: `logger/slogbridge` adapts the `Logger` of its parent,
`logger` (ADR 0032).

## The rule that put them together

A domain belongs here when what it publishes is the process's account of
ITSELF, kept for somebody other than the caller of the call being made: a line
that says what happened (`logger`), a number that says how much (`metrics`), a
span that says how long and on whose behalf (`trace`), and the profiles that
say where the time and the memory went (`profiling`). Readiness and liveness
are the app family's (`pkg/v1/app/health`): they answer a supervisor's question
rather than record what happened.

Each moved here from the root of `pkg/v1` — `pkg/v1/<name>` — in one minor
release, with no alias left at the old path: a clean break, permitted only
while the module is v0 (ADR 0155 §4, extending ADR 0040). The framework's
imports moved in the same change, as did `tools/sdkguard`'s rules, which name
the logger and its bridge by their import paths.

The link-time stamp moved with the logger. `Version` is now
`github.com/kitsunium/sdk/pkg/v1/observe/logger.Version`, and that is the
symbol `x_defs` in `logger/BUILD.bazel` and every `-ldflags -X` recipe name
(root `CLAUDE.md` rule 7).

## Do NOT

- Put Go code in this directory. A file here would publish a package nobody
  designed, at a path every member would then appear to belong to.
- Hand-edit a member's `README.md`: edit its doc comment and run
  `make docs-readme`, whose `--repository.path` names the member's full path.
- Leave an alias package at an old root path. ADR 0155 §4 refuses it: it
  would double the surface for consumers nobody can name.
- Keep a `-ldflags -X` recipe that names the logger's root path. The linker
  ignores `-X` for a symbol that is not in the binary, without a word, and
  every record then reports `framework_version` as `dev`.
