# pkg/v1/session/

## Purpose

Public facade for the SDK's server-side session domain (ADR 0045). Aliases the
`Store` / `Sweeper` / `Sealer` ports and the `ID` / `Session` / `State` value
types, and re-exports the six constructors and all fifteen sentinels.
Stdlib-only → dep-light; the memory store is cross-OS, the file store refuses
honestly where its mechanics do not exist.

## Surface

| Symbol | Notes |
|---|---|
| `Store` | alias onto `core/session`. **Five methods, frozen** — new capabilities are sibling interfaces (ADR 0039) |
| `Sweeper` | the first such sibling. Both stores implement it; reached by type assertion |
| `Sealer` | alias — produces the cookie's VALUE, never the cookie |
| `ID` / `IDLen` | opaque 256-bit identifier; redacts itself, `Reveal` is the only exit, `Equal` is constant-time, `Digest` is what you log |
| `Session` / `State` | short aliases for `SessionValue` / `StateValue` |
| `Config` / `FileConfig` | aliases onto `service/session`. `FileConfig.Key` takes a `pkg/v1/crypto.Key` |
| `NewMemoryStore` / `NewFileStore` | refuse an unusable policy at construction; `NewFileStore` also refuses an unsafe directory and an unsupported platform |
| `NewSealer` | binds a key and a REQUIRED purpose |
| `ParseID` / `NewID` | the inbound path from a cookie, and the raw-bytes path a third-party store needs |
| `NewSession` | builds a `Session` from a `State` — for a framework implementing its own `Store` |
| `NotFound` / `Expired` / `InvalidID` / `InvalidConfig` / `IdentifierCollision` / `EntropyFailed` / `StoreUnavailable` / `SealInvalid` / `FixationRefused` | core sentinels (`0.2.14.*`) |
| `RecordCorrupt` / `DirectoryUnsafe` / `LockFailed` / `PayloadTooLarge` / `InvalidPurpose` | store sentinels (`0.3.46.*`) |
| `UnsupportedPlatform` | the SDK-wide sentinel, shared with `pkg/v1/proc` (ADR 0018) |

## Conventions

- **Type aliases, not new types**; the six constructors are thin delegations.
- **`Regenerate` is the login.** It is the only call that binds a subject and it
  always mints a new identifier. There is no `SetSubject` and no
  `Session.WithSubject` to add — the absence is the fixation defence, and two
  reflection guards in `core/session` fail on anyone who reintroduces one.
  **After a `Regenerate`, re-issue the cookie**: the returned `Session` carries a
  new identifier and the old one no longer resolves.
- **Both timeouts are required and the earlier deadline always wins.** The
  absolute timeout is a ceiling: sliding moves the deadline earlier, never past
  it. `IdleTimeout >= AbsoluteTimeout` is refused, because an idle window the
  ceiling makes unreachable is a sliding expiry the caller believes they
  configured and does not have (ADR 0031).
- **Rotating does not buy time** unless the principal changed. Same subject
  keeps the original ceiling; a different subject restarts both clocks.
- **Every "no usable session" verdict is HTTP 401.** `errs.HTTPStatusOf` routes
  the whole family, so a framework needs no switch. `StoreUnavailable` is 503.
- **The frontier.** This package ships the store and the sealing. The firewall,
  the voters, the login conventions and writing the cookie onto an HTTP response
  belong to the framework. `Sealer.Seal` gives you the value; `http.SetCookie` is
  your line.
- **A session is not a token.** `pkg/v1/token` is self-contained and
  unrevocable; a session is an opaque handle whose facts live in the store, so
  `Destroy` takes effect on the next request. The package doc leads with this
  because the two are constantly confused.

## Do NOT

- **Reimplement a store here** — the facade is aliases + delegations.
- **Log `ID.Reveal()`.** Log `ID.Digest()`: it correlates and it is not a
  bearer secret.
- **Add a method to `Store`, `Sweeper` or `Sealer`.** All three are aliased, so
  the shape is published (ADR 0039). Add a sibling.
- **Write an HTTP helper here.** Not a cookie writer, not a middleware, not a
  `FromRequest`. That is the frontier, and crossing it is how a session store
  becomes an authentication framework.
- **Treat a value that `Open`s as authenticated.** It proves only that someone
  holding the key minted it; whether it names a live session is `Store.Load`'s
  answer.
