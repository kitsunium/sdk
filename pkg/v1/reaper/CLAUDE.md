# pkg/v1/reaper/

## Purpose

Public **PID1 / subreaper zombie-collector** facade (ADR 0016). Thin alias +
delegation over `internal/service/proc/reaper` — zero runtime cost, no business
logic (per `pkg/` convention). Lets a container init or any supervisor reap
orphaned descendants instead of leaking zombies.

## Surface

| Identifier | Role |
|---|---|
| `Reaper` | alias of `coreproc.Reaper` (Start / Stop / ReapOnce) |
| `Option` | alias of the service option type |
| `WithOnReap(func(int)) Option` | post-sweep observer (count per sweep; must not block) |
| `New(opts ...Option) Reaper` | construct an idle reaper; Unix loop or no-op |
| `SetChildSubreaper() error` | `prctl(PR_SET_CHILD_SUBREAPER, 1)`; Linux only |
| `IsPID1() bool` | `os.Getpid() == 1` (false off Unix) |
| `ReapFailed` / `SubreaperFailed` / `UnsupportedPlatform` | re-exported central sentinels for `errs.HasCode` matching |

Public types are **aliases** of the core/service types — never new types.

## Why-this-shape

- The facade adds nothing but ergonomics: `New` forwards to the platform-selected
  service constructor; the three funcs delegate one-to-one. Keeping it a pure
  pass-through preserves the `pkg/v1` rule that consumer surface holds no logic.
- The sentinels are re-exported as `var` aliases so a consumer matches a reaper
  failure (`errs.HasCode(err, reaper.ReapFailed.Code())`) without importing any
  `internal/*` package.
- `Reaper` is an interface alias, so `New` can return the Unix loop or the no-op
  stub behind one type across every GOOS.

## Semantics (delegated)

- `Start` is idempotent; `Stop` runs a final drain and joins the goroutine (no
  zombie, no goroutine leak); `ReapOnce` is a single concurrency-safe sweep.
- `ECHILD` is a clean sweep terminus, not an error; other wait errors →
  `ReapFailed`.
- Off Unix everything degrades: `New` is a no-op reaper, `SetChildSubreaper`
  returns `UnsupportedPlatform`. On non-Linux Unix the loop works but
  `SetChildSubreaper` is `UnsupportedPlatform`.
