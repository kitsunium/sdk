# pkg/v1/tlsid/

## Purpose

Public façade for TLS and mutual-TLS identities (ADR 0029). Aliases onto
`internal/core/net` plus two thin delegating constructors — `New` for material
already in memory, `Load` for material on disk. No logic lives here.

Shared by **both** faces of the network domain: `pkg/v1/client` uses an Identity
for outbound mTLS, `pkg/v1/server` uses the same type for inbound. One identity
type means the validation and redaction rules cannot drift between them.

## Surface

| Symbol | Role |
|---|---|
| `Identity` | alias of `corenet.IdentityValue` — opaque, redacting |
| `Params` | alias of `corenet.IdentityParams` — in-memory material |
| `FileParams` | alias of `svctlsid.FileParams` — on-disk material |
| `New(Params) (Identity, error)` | validate in-memory material |
| `Load(FileParams) (Identity, error)` | read + validate on-disk material |
| `MaterialInvalid` | sentinel `0.2.11.15` — missing/malformed/unusable material |
| `HandshakeFailed` | sentinel `0.2.11.16` — handshake did not complete |

`Identity.ClientConfig()` / `.ServerConfig()` mint a **fresh** `*tls.Config` per
call. There is deliberately **no** accessor for the raw certificates, private key
or PEM bytes.

## Why-this-shape

- **The sentinels are re-exported as vars** so a consumer can write
  `errors.Is(err, tlsid.MaterialInvalid)` without reaching into `internal/*`,
  which Go's `internal/` firewall forbids anyway. `TestSentinelIsMatchable`
  pins it.
- **`README.md` is generated by gomarkdoc** (rule 10) from the package doc
  comment in `tlsid.go`. Edit the doc comment, then `make docs-readme`. Do not
  hand-edit the README.
- **Consumer-facing prose lives in the package doc comment**, maintainer
  rationale lives here. That is why the godoc carries the runnable examples and
  the explanation of the `AppendCertsFromPEM` trap.
- **The tests do a real handshake.** `TestMutualTLSRoundTrip` stands up a real
  `tls.Listener`, dials it, and asserts TLS 1.3 plus a presented peer
  certificate. Asserting struct fields alone would have passed while the
  identity was unusable — the handshake test immediately caught a fixture
  relying on the legacy CommonName field, which Go refuses to verify.

## Do NOT

- Add validation here. It belongs in `internal/core/net`.
- Expose the certificate chain, private key, or PEM bytes.
- Hand-edit `README.md` — regenerate it.
- Log an `Identity` expecting redaction to be enough justification for logging
  it at all; it renders `"<redacted>"` under every verb, so it carries no
  information worth a log line.
