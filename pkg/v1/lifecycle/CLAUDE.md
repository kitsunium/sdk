# pkg/v1/lifecycle/

## Purpose

Public facade for the SDK's ordered start/stop domain (ADR 0050). Aliases the
`Start`/`Stop`/`Lifecycle` port and the three domain values, re-exports the two
constructors, the `Phase` constants, `DefaultStopTimeout` and all nine
sentinels. Stdlib-only → dep-light; cross-OS portable.

## Surface

| Symbol | Notes |
|---|---|
| `Start` / `Stop` / `Lifecycle` | aliases onto `core/lifecycle`. Both `Start` and `Stop` are FUNC types, so neither can grow a method (ADR 0039) |
| `Component` / `Transition` / `Phase` | short aliases for `ComponentValue` / `TransitionValue` / `Phase` |
| `Signal` | alias onto `core/proc.Signal`, so wiring `RunConfig.Signals` needs no second import |
| `Config` / `RunConfig` | aliases onto `service/lifecycle` |
| `New` | cannot fail: a nil `Clock` falls back to the wall clock, a non-positive `StopTimeout` to `DefaultStopTimeout`, a nil `OnTransition` to no observation |
| `Run` | start → wait on ctx or a subscribed signal → stop. The zero `RunConfig` wires nothing |
| `DefaultStopTimeout` | 30s. Exported because a default nobody can name is a default nobody can reason about |
| `PhaseStart` / `PhaseStop` | the closed two-value set |
| `InvalidComponent` / `DuplicateComponent` / `LifecycleRunning` / `ComponentPanicked` | core sentinels (`0.2.19.*`) |
| `StartFailed` / `StopFailed` / `StopTimeout` / `UnwindFailed` / `ReadinessFailed` | engine sentinels (`0.3.49.*`) |

## Conventions

- **Type aliases, not new types**; the two constructors are thin delegations.
- **The Add order IS the dependency order**, and shutdown is its exact reverse.
  No graph, no cycle detection, no parallel start, no autowiring — ADR 0050
  §D1/§D2 record those as decisions rather than omissions, so the next proposal
  meets an answer.
- **A failed start is cleaned up before `Start` returns.** The consumer-facing
  version of the guarantee is in the package doc comment (rule 10); the
  mechanics are in `internal/service/lifecycle/CLAUDE.md`.
- **An expired budget cancels a context and stops waiting.** It never kills a
  goroutine and never closes anything the component owns. Consumers reading
  only this package need that stated here, because it is the difference between
  "my Stop was interrupted" and "my Stop was told to hurry".
- **Errors are `errors.Join` aggregates.** Match the SDK's verdict with
  `errs.HasCode`, the component's own error with `errors.Is`. Both work on the
  same value, which is why the aggregate is a join and not a wrap.
- README generated by gomarkdoc; edit the `lifecycle.go` doc comment +
  `make docs-readme`.

## Do NOT

- Reimplement ordering, budgets, signal handling or sd_notify here — the facade
  is aliases + delegations.
- Add a "start everything in parallel" helper. It is not a facade concern, and
  ADR 0050 §D1 rejects it at the domain level.
- Document the mechanics of the unwind here instead of in the package doc
  comment. Consumer-facing prose belongs where gomarkdoc renders it (rule 10);
  this file is maintainer rationale.
