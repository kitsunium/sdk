# pkg/v1/view/

## Purpose

Public facade for the SDK's server-side rendering (ADR 0058). Re-exports the
port, the config, the factory contract and the one trust type as **type
aliases** (zero runtime cost), plus the two constructors, the registry entry
points and every sentinel, so consumers depend only on `pkg/v1`.

Importing this package is what wires the `html` engine: the facade imports
`internal/service/view` for `New`, and that import runs the registration.

## Conventions

- **Type aliases, not new types** — `pkg/v1/view.Renderer` IS
  `core/view.Renderer`, so a consumer's implementation satisfies both.
- **Parse once.** Build the `Renderer` at start-up and keep it: it is immutable
  and concurrency-safe. Per-request construction costs 34× on a realistic tree
  (`internal/service/view/BENCH.md`). The rule is in the package doc comment
  because that is what a consumer reads.
- **Render returns bytes, never taking a writer.** A mid-execution failure must
  not have already flushed a status line and half a page.
- **`New` fails loudly for a broken tree**, and returns a genuinely nil
  `Renderer` when it does — guarded by
  `TestABrokenTreeIsRefusedAndTheRendererIsGenuinelyNil`.
- README generated by gomarkdoc; edit the `view.go` doc comment and run
  `make docs-readme`.

## Do NOT

- **Weaken the "what `Trusted` does not prevent" paragraph in the package doc
  comment.** `view.TrustHTML(r.FormValue("bio"))` compiles and is stored XSS,
  and the SDK cannot see it: `TrustedHTML` is a type alias, so a fragment
  marked through `TrustHTML` is indistinguishable from a raw
  `template.HTML(…)` conversion. The domain prevents an ACCIDENTAL bypass and
  gives the deliberate one one greppable name. Stated in four places on
  purpose.
- **Add a spelling for any of the other six trust types.** `CSS`, `HTMLAttr`,
  `JS`, `JSStr`, `URL` and `Srcset` are refused in render data; a `TrustURL`
  would hand callers the exact primitive
  `template.URL("javascript:alert(1)")` exploits.
- **Add a method to any aliased interface** — it breaks every downstream
  implementer at compile time with no deprecation window (ADR 0039).
- **Import `text/template` here.** The AST audit in `internal/service/view`
  covers this package too, production and test files alike.
- **Add a `RenderTo(w io.Writer, …)` convenience.** It re-creates the exact
  defect the port's signature exists to prevent.
- **Add layouts, blocks, helper libraries, i18n or an asset pipeline.** They
  are framework opinions; composition is `html/template`'s `{{define}}` and
  `{{template}}`.
