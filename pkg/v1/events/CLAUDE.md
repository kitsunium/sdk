# pkg/v1/events/

## Purpose

Public facade for the SDK's **in-process event bus** (ADR 0053). Aliases the
`Bus` / `Listener` port, the `EventType` / `Priority` / `Subscription` /
`Dispatch` values and the typed `Handler[E]`, re-exports `New`, the two generic
registration functions, `PriorityNormal` and all eight sentinels. Stdlib-only →
dep-light; cross-OS portable.

## Surface

| Symbol | Notes |
|---|---|
| `Bus` / `Listener` | aliases onto `core/events`. `Listener` is a FUNC type, so it cannot grow a method; `Bus` is frozen at three methods (ADR 0039) |
| `EventType` / `Priority` / `Subscription` / `Dispatch` | short aliases for `reflect.Type`, `Priority`, `SubscriptionValue`, `DispatchValue` |
| `Handler[E]` | generic type alias onto `service/events.Handler[E]` — the typed registration a caller writes |
| `New` | cannot fail and takes no configuration; every knob considered was a contract, not a setting |
| `On[E]` / `Off[E]` | the generic registration and removal. Functions, not methods, because Go methods take no type parameters — and a `Bus[E]` carries one event type, which is a channel |
| `PriorityNormal` | the zero `Priority`; negative runs before it, positive after |
| `Halt` | the control sentinel a listener returns to stop the dispatch. Only a `MayHalt` listener may use it |
| `InvalidSubscription` / `DuplicateListener` / `UnknownListener` / `InvalidEventType` / `ListenerPanicked` | core sentinels (`0.2.22.*`) |
| `ListenerFailed` / `HaltNotPermitted` | engine sentinels (`0.3.52.*`) |

## Conventions

- **Type aliases, not new types**; `New` / `On` / `Off` are thin delegations.
- **The frontier belongs in the package doc comment, not here.** A consumer
  reaching for an event bus when they need a queue is the single most expensive
  mistake this package can let happen, so the `events` / `queue` table is the
  first thing `README.md` renders (rule 10). This file is maintainer rationale.
- **`Halt` has to be re-exported** or a consumer could not stop a dispatch
  without importing an internal package the firewall forbids them.
  `TestHaltIsReachableThroughTheFacade` is the guard.
- **Errors are `errors.Join` aggregates.** Match the SDK's verdict with
  `errs.HasCode(err, events.ListenerFailed.Code())`, the listener's own error
  with `errors.Is`. Both work on the same value, which is why the aggregate is
  a join and not a wrap.
- README generated by gomarkdoc; edit the `events.go` doc comment +
  `make docs-readme`.

## Do NOT

- **Add an `Emit[E]` helper** — or any second way to publish. `bus.Publish(ctx,
  ev)` is already typed at the call site; only *registration* needs a type
  parameter, because that is the one place the type is not otherwise present. A
  second spelling buys nothing and costs every reader a choice.
- Reimplement ordering, the halt or the panic guard here — the facade is
  aliases plus three delegations.
- Add an asynchronous or buffered publish. See ADR 0053 §D1: that is the
  `queue` domain, and half of it is worse than none of it.
- Document the dispatch mechanics here instead of in the package doc comment.
  Consumer-facing prose belongs where gomarkdoc renders it (rule 10).
