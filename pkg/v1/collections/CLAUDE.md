# pkg/v1/collections/

## Purpose

The data-structure family's public facades (ADR 0155 §1, ADR 0159 §4). This
directory holds no Go code: it is a prefix, not a package, and there is no
`github.com/kitsunium/sdk/pkg/v1/collections` to import. Each member is a
package of the SDK module with its own `CLAUDE.md` and `README.md`
(generated by gomarkdoc from its doc comment, ADR 0008), imported by its full
path — `github.com/kitsunium/sdk/pkg/v1/collections/heap`.

Every member is a pure alias of the kernel package at the same path under
`internal/kernel/collections`: type aliases, a forwarding constructor and the
package's sentinels, no behaviour of its own — published so a program, and
the framework, which reaches the SDK through `pkg/v1` alone (ADR 0147), keeps
its values in the containers the SDK's own services use.

## The rule that put them together

The kernel's (`internal/kernel/collections/CLAUDE.md`): a package belongs here
when what it IS is a container of values, generic in its element — kept in an
order (`heap`) or within a bound (`ring`). Each is safe for its documented
callers — `heap` for one at a time, `ring` for one producer and one consumer —
but that is a property of the container, not the reason it exists.

## Members

| Package | What it publishes | Aliases onto | README |
|---|---|---|---|
| `heap/` | `New` → a `Heap[T]` ordered by the caller's comparison: `Push`, `Pop` / `Peek` → `(T, bool)`, `Len` | `internal/kernel/collections/heap` | `heap/README.md` |
| `ring/` | `New` → a `Queue[T]` for one producer and one consumer, `TryWrite` / `TryRead` refusing with `Full` / `Empty` instead of blocking; `CapZero` (ADR 0006) | `internal/kernel/collections/ring` | `ring/README.md` |

`cache`, the kernel's third member, is published where its domain is:
`pkg/v1/data/cache` holds the LRU+TTL primitive beside the cache domain built
on it (ADR 0049).

## Do NOT

- Put Go code in this directory. A file here would make `collections` a
  package of its own.
- Give a member behaviour. A shape an alias cannot express lands in the kernel
  package first and is forwarded in the same change.
- Hand-edit a member's `README.md`: edit its doc comment and run
  `make docs-readme`.
