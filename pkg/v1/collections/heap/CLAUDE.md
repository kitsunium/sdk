# pkg/v1/collections/heap/

## Purpose

Public facade for `internal/kernel/collections/heap` (ADR 0159 §4): a binary
heap of any element type, ordered by the caller's comparison — `Push` and
`Pop` in O(log n), `Peek` in O(1), `(zero, false)` on an empty heap. An alias
and one forwarding constructor — no behaviour of its own. Stdlib-only →
dep-light; cross-OS portable.

It is the heap under the state machine's agenda (ADR 0120) and the in-memory
queue broker's lease expiries, published so a program — and the framework,
which reaches the SDK through `pkg/v1` alone (ADR 0147) — keeps a priority
queue without `container/heap`'s five-method boilerplate and its `any` boxing.

## Surface

| Symbol | Notes |
|---|---|
| `Heap[T]` | alias; `Push`, `Pop` / `Peek` → `(T, bool)`, `Len`. The zero value is NOT usable; NOT safe for concurrent use |
| `New[T](cmp)` | `cmp` follows `cmp.Compare`: the element that sorts first is on top. A nil `cmp` panics here |

That is the complete exported surface of `internal/kernel/collections/heap`.

## Conventions

- **Min-heap by `cmp.Compare`, max-heap by swapping its arguments** — said in
  the package comment and shown in `ExampleNew`, because the direction is the
  first question anybody asks of a heap.
- **No lock, on purpose**: the caller picks the lock, or holds the heap inside
  a structure it already serialises — the two SDK consumers both do.
- **Methods are documented on the alias** and linked `[Heap].Pop` (ADR 0138).
- README generated by gomarkdoc; edit the `heap.go` doc comment and run
  `make docs-readme`.

## Do NOT

- Add a `Fix`, a `Remove(i)` or a stable variant here. A shape the alias
  cannot express lands in the kernel package first — and a stable heap is a
  different structure, not an option.
- Reach for `internal/kernel/collections/heap` in this package's tests.

## Verification

```
bazel test --config=race //pkg/v1/collections/heap:heap_test
cd pkg && GOWORK=off go test -race ./v1/collections/heap/
```

`heap_external_test.go` is `package heap_test`: a min-heap and a max-heap from
one comparison, `Peek` agreeing with `Pop`, `(zero, false)` on an empty heap,
a nil comparison panicking at `New` — plus `ExampleNew`, a priority queue.
