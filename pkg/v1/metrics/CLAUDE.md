# pkg/v1/metrics/

## Purpose

Public facade for the SDK observability domain (ADR 0027), the logger's twin.
Aliases the `Meter`/instrument/`Exporter` types + `SnapshotValue`, exposes
`NewMeter`, `Export`, `RegisterExporter`, `NewTextExporter`, `AvailableExporters`,
and the sentinels. The default `text` exporter registers on import and writes to
**stderr** (ADR 0030) — importing a package must not arm a writer on stdout,
which the process may be using as a protocol channel. Stdlib-only → dep-light;
cross-OS.

## Surface

| Symbol | Notes |
|---|---|
| `Meter` / `Counter` / `Gauge` / `Histogram` | instrument aliases |
| `Snapshot` (= `SnapshotValue`) / `HistogramValue` | exportable value aliases |
| `Exporter` / `ExporterName` | exporter aliases |
| `NewMeter()` | in-memory Meter (Counter/Gauge/Histogram + Collect) |
| `Export` / `RegisterExporter` / `NewTextExporter` / `AvailableExporters` | registry verbs |
| `UnknownExporter` / `ExportFailed` / `InstrumentKindConflict` | sentinels |

## Conventions

- **Type aliases, not new types**; constructors are thin delegations.
- **stdout is opt-in**: `NewTextExporter(name, os.Stdout)` binds it explicitly;
  the registered `text` exporter never does (ADR 0030).
- v1 is **label-free**; Prometheus/OTLP exporters are deferred (ADR 0027).
- README generated by gomarkdoc; edit the `metrics.go` doc comment + `make docs-readme`.

## Do NOT

- Reimplement instruments here — the facade is aliases + wrappers.
