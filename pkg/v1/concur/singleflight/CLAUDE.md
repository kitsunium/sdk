# pkg/v1/concur/singleflight/

## Purpose

Public facade for `internal/kernel/concur/singleflight` (ADR 0159 §4): one
execution per key however many callers arrive while it runs, the call
outliving any single caller, and a panic re-raised in every waiter. Aliases
only — no behaviour of its own. Stdlib-only → dep-light; cross-OS portable.

It is the primitive under the `cache` domain's stampede protection (ADR 0049),
published so a program — and the framework, which reaches the SDK through
`pkg/v1` alone (ADR 0147) — collapses its own bursts of identical work without
`golang.org/x/sync`.

## Surface

| Symbol | Notes |
|---|---|
| `Group[K, V]` | alias; `Do(ctx, key, fn)` → `(value, shared, err)`, `Forget(key)`, `InFlight()`. The zero value is ready; must not be copied after first use |
| `PanicValue` | alias; `Raised` + `Stack`, re-raised in every waiter; deliberately NOT an error |

That is the complete exported surface of `internal/kernel/concur/singleflight`
— it has no constructor. Nothing is held back and nothing is added.

## Conventions

- **Aliases, not new types.** A `Group[K, V]` built here is the type the cache
  domain holds; `recover().(singleflight.PanicValue)` matches what it
  re-raises.
- **Whose context, stated on the alias.** `fn` receives the FIRST caller's
  values with every deadline removed, cancelled only when the last caller has
  left. The package comment says so because it is the one behaviour a reader
  of `golang.org/x/sync/singleflight` would not expect.
- **Methods are documented on the alias** and linked `[Group].Do` (ADR 0138).
- README generated by gomarkdoc; edit the `singleflight.go` doc comment and
  run `make docs-readme`.

## Do NOT

- Add a `DoChan`, a result cache or a cross-process mode here. A shape the
  alias cannot express lands in the kernel package first; a cache is the
  `data/cache` domain's job, and a cross-replica lease is a distributed system.
- Reach for `internal/kernel/concur/singleflight` in this package's tests.

## Verification

```
bazel test --config=race //pkg/v1/concur/singleflight:singleflight_test
cd pkg && GOWORK=off go test -race ./v1/concur/singleflight/
```

`singleflight_external_test.go` is `package singleflight_test`. It asserts the
STRICT claim — exactly one execution for eight concurrent callers, seven of
them told `shared` — inside a `testing/synctest` bubble, where
`synctest.Wait` makes "every follower has joined" a fact rather than a timing
guess; then `Forget` starting a fresh call while the forgotten one still
answers its caller, and a panic re-raised as `singleflight.PanicValue`; plus
`ExampleGroup`.
