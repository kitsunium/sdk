# pkg/v1/concur/snapshot/

## Purpose

Public facade for `internal/kernel/concur/snapshot` (ADR 0159 §4, ADR 0011):
a copy-on-write container — `Load` is one atomic load with no lock and no
allocation, and the writers publish whole new values serialised on a mutex,
so a read-modify-write never loses a concurrent one. An alias and one
forwarding constructor — no behaviour of its own. Stdlib-only → dep-light;
cross-OS portable.

It is the container every registry of the SDK is built on (codecs, writers,
exporters, the generic `plugin.Registry`), published so a program — and the
framework, which reaches the SDK through `pkg/v1` alone (ADR 0147) — stops
hand-rolling an `atomic.Pointer` whose writers either forget the lock or retry
a compare-and-swap.

## Surface

| Symbol | Notes |
|---|---|
| `Value[T]` | alias; `Load` (lock-free), `Store`, `Swap` (returns the previous pointer), `Update(fn)` (read-modify-write under the writers' lock). The zero value is ready and holds nil; must not be copied after first use |
| `NewValue[T](initial)` | sugar for a value known up front; a nil `initial` is the zero value |

That is the complete exported surface of `internal/kernel/concur/snapshot`.

## Conventions

- **When `atomic.Pointer` is still the right tool.** A pointer published once
  and swapped wholesale (`Store` / `Load` / `Swap`, or a compare-and-swap that
  CLAIMS ownership) gains nothing from this package — it would add a writer
  mutex and lose `CompareAndSwap`. `Value` earns its place where a writer
  CLONES the current value, changes the clone and publishes it: there
  `Update` is the one step that cannot lose a concurrent write. The package
  comment draws the same line for a consumer.
- **The pointer `Load` returns is immutable by contract**, and an `Update`
  function must not call back into the same `Value` (deadlock) — both stated
  in the package comment, as the kernel states them.
- **Methods are documented on the alias** and linked `[Value].Update`
  (ADR 0138). Forwarding constructor, not a `var` (see `data/semver`).
- README generated by gomarkdoc; edit the `snapshot.go` doc comment and run
  `make docs-readme`.

## Do NOT

- Add a `CompareAndSwap`, a typed map wrapper or a clone helper here. A shape
  the alias cannot express lands in the kernel package first.
- Reach for `internal/kernel/concur/snapshot` in this package's tests.

## Verification

```
bazel test --config=race //pkg/v1/concur/snapshot:snapshot_test
cd pkg && GOWORK=off go test -race ./v1/concur/snapshot/
```

`snapshot_external_test.go` is `package snapshot_test`: the empty states,
`Store` / `Swap` / `Load` by pointer identity, sixty-four racing `Update`s that
lose no key — the bug the package exists to prevent, judged under the race
detector — and the abort idiom, plus `ExampleValue`. The zero-allocation
`Load` is pinned by the kernel package's alloc-lane gate.
