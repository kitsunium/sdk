# pkg/v1/concur/group/

## Purpose

Public facade for `internal/kernel/concur/group` (ADR 0159 §4): structured
concurrency — N tasks, one wait, a bounded parallelism, the first error or
every error joined, and a task's panic delivered to the waiter. Aliases and
forwarding functions only — no behaviour of its own. Stdlib-only → dep-light;
cross-OS portable.

It exists so a program, and first of all the framework (which reaches the SDK
through `pkg/v1` and `kernel/errs` only, ADR 0147), runs its fan-outs on the
primitive the SDK's own `health` probe and `queue` consumer run on, instead of
a `sync.WaitGroup`, a semaphore channel and an error variable written again.

## Surface

| Symbol | Notes |
|---|---|
| `Group` | alias; `Go(fn)` / `Wait()`. The zero value is NOT usable; used once |
| `New(parent, limit)` | first-error group and the context its tasks receive; the first failure is the context's `Cause` |
| `NewJoined(parent, limit)` | every failure, `errors.Join`ed in submission order; nil — not an empty join — when none |
| `Collect[T](parent, limit, fns)` | results in SUBMISSION order; `(nil, err)` on the first failure, never a half-filled slice |
| `Unlimited` | the limit that bounds nothing — `limit < 1` is clamped to 1, never read as "no limit" |
| `PanicValue` | alias; `Raised` + `Stack`, re-raised by `Wait` / `Collect`; deliberately NOT an error |

That is the complete exported surface of `internal/kernel/concur/group`.
Nothing is held back and nothing is added.

## Conventions

- **Aliases, not new types.** `group.PanicValue` IS the kernel type, so a
  `recover().(group.PanicValue)` written by a consumer matches what the SDK's
  own services re-raise.
- **Forwarding functions, not `var` aliases**, as `data/semver` does: each
  constructor carries its own doc comment, so `go doc`, pkg.go.dev and the
  generated README show its signature instead of a variable of function type.
- **Methods are documented on the alias** and linked `[Group].Go` (ADR 0138):
  go/doc collects no methods for an alias.
- README generated by gomarkdoc; edit the `group.go` doc comment and run
  `make docs-readme`.

## Do NOT

- Add a helper, a default limit or a convenience wrapper here. A shape the
  alias cannot express lands in `internal/kernel/concur/group` first and is
  forwarded in the same change — a facade that grows logic is a second
  implementation.
- Turn `PanicValue` into an error, or read a zero limit as "unbounded" — both
  are decisions of the kernel package, documented in its `CLAUDE.md`.
- Reach for `internal/kernel/concur/group` in this package's tests. The test
  names `pkg/v1` only, so it proves the public surface rather than the kernel's.

## Verification

```
bazel test --config=race //pkg/v1/concur/group:group_test
cd pkg && GOWORK=off go test -race ./v1/concur/group/
```

`group_external_test.go` is `package group_test` and drives every symbol
through its public name: the first failure as `Wait`'s result and the
context's cause, every failure joined, `Collect`'s submission order with tasks
finishing in reverse, a panic re-raised as `group.PanicValue`, the clamp of a
zero limit and `Unlimited` through a barrier — plus `ExampleCollect` and
`ExampleNewJoined`. The primitive itself is proved in the kernel's suite.
